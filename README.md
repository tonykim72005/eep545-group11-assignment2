# localization

This repository contains the starter code for Assignment 2: localization for the Autumn 2024 offering of EE P 545.

Q1: There are more particles within a 10cm radius in the noise-free model (fig. 2) because it does not take into account the noise that is generated by the system which can lead to errors. The fig. 2 plot assumes it is a perfect system: it has perfect sensors that don't make mistakes and have infinite resolution, the motors respond perfectly to applied voltage and the battery always has a perfect output. Since fig. 3 takes into account all these noises from the real world and assumes what could go wrong with the system numerically, it obviously presents more possibilities spread out in the map.
Q3: The drawbacks of the conditional independence assumption is not true, the belief of the state of the car is dependent on both the sensor and motion models, both have valuable information on where is the current state of the car. We mitigate this drawback with the Bayes rule, as it takes both of these seemingly independent inputs and combines them to have a dependent probabilistic model
